# AI Usage Report

## Tools Used & Use Cases

### ChatGPT

I used ChatGPT as a supporting tool during this assignment.

I completed the project by following the assignment requirements, creating the project structure, adding the content, testing the website, and reviewing the final result.

ChatGPT was mainly used to:

- Explain some assignment requirements
- Suggest ways to organize the project
- Provide examples and suggestions for HTML, CSS, and JavaScript
- Help review the code and identify possible improvements
- Suggest responsive design ideas
- Assist with writing and organizing the documentation
- Getting guidance on the Git and GitHub workflow for committing and uploading the project

The AI suggestions were used as guidance and were reviewed before being added to the project.

## Benefits & Challenges

### Benefits

Using ChatGPT helped me understand some steps faster and gave me useful suggestions when I was unsure about how to organize or implement parts of the project.

It was especially helpful for explaining web development concepts and providing examples that I could review and apply to my own project.

### Challenges

AI suggestions still need to be checked because they may include incorrect assumptions or information that does not match the assignment, and it happens many times but I was in focus to catch it.

For this reason, I compared the suggestions with the assignment requirements and tested the website myself.

I also changed information and content when it did not correctly represent me or my project.

## Learning Outcomes

While completing this assignment, I improved my understanding of:

- HTML structure
- CSS styling
- Responsive web design
- Flexbox and CSS Grid
- Media queries
- Basic JavaScript event handling
- Dark and Light theme switching
- Contact form interaction
- Organizing a web project into separate files
- Basic Git and GitHub workflow

I also learned how AI can be used as a development assistant while still requiring the developer to understand, review, and test the final work.

## Responsible Use & Modifications

I did not use AI output without reviewing it.

I checked the generated suggestions, compared them with the assignment requirements, and made changes when needed.

For example, I corrected personal information in the portfolio so that it accurately identifies me as a Computer Science student at KFUPM.

I also tested the website myself, including the navigation, responsive layout, project section, Dark/Light mode, and contact form interaction.

The final decisions, testing, and review of the project were done by me, while ChatGPT was used as a supporting and learning tool.
